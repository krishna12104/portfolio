# Portfolio Website

A clean, responsive portfolio website structure that presents your story, skills, projects, and career goal clearly.

## What’s included

- `index.html` — homepage with sections for About, Skills, Projects, Career Goal, and Contact.
- `styles.css` — modern responsive design with gradient background and clean cards.
- `script.js` — small script to keep the footer year current.
- `.gitignore` — basic ignores for GitHub.

## Customize your portfolio

1. Open `index.html`.
2. Replace the placeholder name, description, contact email, and GitHub link.
3. Update the Skills and Projects sections with real examples.
4. Add a real career goal and message in the Career Goal section.

## Run locally

1. Open `index.html` directly in your web browser.
2. Or use VS Code Live Server if installed: right-click `index.html` and choose "Open with Live Server".
3. The page will load in your browser and show the portfolio website instantly.

## Git and GitHub setup

Initialize a local Git repository:

```bash
git init
git add .
git commit -m "Initial portfolio website"
```

If you already have a GitHub repository, connect it with:

```bash
git remote add origin https://github.com/your-username/your-repo.git
git branch -M main
git push -u origin main
```
